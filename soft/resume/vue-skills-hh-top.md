# Топ навыков Vue Frontend на hh.ru

### Что это за списки

Мы прошлись по актуальным вакансиям Vue / Frontend (Vue) на hh.ru, убрали дубли и разобрали каждую на составляющие. Получился список:

- **Навыки** — то, что работодатели вписывают в раздел «Ключевые навыки» вакансии (Vue.js, TypeScript, Git, REST API и т.д.). Рядом с каждым стоит цифра — в скольких вакансиях он встретился.

Список отсортирован по убыванию: чем выше навык, тем чаще он нужен рынку прямо сейчас.

### Почему это важно

- **Резюме читает не только человек, но и робот.** Первичный отбор на hh и в ATS-системах идёт по совпадению навыков. Чем больше «тяжёлых» (частотных) навыков из этого списка есть у тебя в резюме — тем выше ты в поиске рекрутера и тем чаще твой отклик вообще доходит до живого человека.
- **Формулировка решает.** Система засчитывает точное написание. `Vue.js`, `VueJS`, `Vue` и `vue.js` — для неё разные вещи, и вес у них разный. Один и тот же навык, названный «канонично», приносит больше очков. Списки показывают, как рынок называет вещи чаще всего — под этот язык и стоит подстраивать резюме.
- **Это карта приоритетов в обучении.** Если выбираешь, что подтянуть следующим — смотри наверх списка. Навык из топа закроет больше вакансий, чем редкая экзотика снизу. Не распыляйся на то, что просят единицы.

### Промпт для Claude — посчитать вес навыков в своем резюме

Загрузи Claude свой файл с **резюме** и наш файл с топом навыков `vue-skills-hh-top.md`, а затем вставь этот промпт:

```text
У меня есть таблица навыков с весами (вес = число вхождений по вакансиям) и резюме.

1. Из раздела «Навыки» проставь каждому навыку вес из таблицы (точное написание; нет → 0).
2. Выведи «навык | вес» по убыванию + сумму.
3. Помечай мёртвый вес: 0 и дубли (TS=TypeScript, Vue=Vue.js=VueJS) — с каноничным названием из таблицы.
4. Предложи прибавку веса только из того, что есть в моём опыте, но не в «Навыках»:
   «добавить/исправить | +вес | основание». Дубли (Vue+VueJS+Vue.js) считай накруткой — бери канон с максимальным весом.

Работай только с разделом «Навыки». Остальные части резюме не комментируй и не улучшай.
Цель — максимум веса без выдуманных навыков.
```

Claude вернёт таблицу с текущим весом навыков резюме, подсветит слабые места и предложит конкретные правки с весом прибавки.
