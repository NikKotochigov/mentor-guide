# useLocalStorage без рассинхрона

Время: 30-40 минут (около 15 на код, остальное на обсуждение).

Нужен хук `useLocalStorage(key, initialValue)`, чтобы хранить значение в `localStorage`. В `App.tsx` уже есть заготовка и демо: настройки имени и темы плюс отдельный предпросмотр. Заготовка работает с ошибками.

## Что сделать

Реализуй `useLocalStorage` так, чтобы:
- значение переживало перезагрузку страницы;
- два компонента с одним и тем же `key` показывали одно значение и обновлялись вместе;
- изменение в другой вкладке того же сайта тоже подхватывалось;
- источником правды был `localStorage`, а не копия в `useState`.

Компоненты демо менять не нужно, правь только хук.

Чтобы открыть в StackBlitz, создай проект Vite React TypeScript и замени `src/App.tsx` этим файлом.

## Как проверить

- В блоке "Настройки" меняешь имя: в "Предпросмотр" оно появляется сразу, без перезагрузки.
- Переключаешь тему: фон страницы и подпись в предпросмотре меняются вместе.
- Перезагрузка страницы оставляет имя и тему на месте.
- Если открыть то же демо во второй вкладке, изменение имени или темы сразу видно и там.
