# Данные через Suspense

Время: 30-40 минут (около 15 на код, остальное на обсуждение).

Профиль сейчас должен грузить данные через Suspense: пока данных нет, компонент приостанавливается, снаружи показывается fallback. Без `useEffect`.

## Что сделать

1. `getUser(id)` ходит в `fetchUser(id)` и кладёт результат в кэш.
   Повторный вызов с тем же id не создаёт новый запрос.
   Если промис ещё не готов, бросает этот промис (так Suspense поймёт, что нужно подождать).
   Если запрос упал, бросает ошибку.
   Если данные есть, возвращает их.
2. `useUser(id)` читает данные через `getUser`.
3. В `Profile` не должно быть `useEffect`.

Код пиши в `src/useUser.tsx`. `fetchUser` уже есть в `src/api.ts`, его менять не нужно. Компоненты в `src/App.tsx` тоже готовы.

## Как проверить

- При первом рендере виден fallback "Загрузка...", затем имя.
- Кнопка "Сменить пользователя" с id "2" запускает новый запрос и снова показывает fallback.
- Возврат к id "1" не должен логировать второй fetch "1" (смотри `console.log`).
