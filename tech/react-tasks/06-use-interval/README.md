# useInterval без stale closure

Время: 30-40 минут (около 15 на код, остальное на обсуждение).

Нужен хук `useInterval(callback, delay)` для таймера. В `App.tsx` уже есть заготовка хука и демо: счётчик, пауза и шаг. Заготовка работает с ошибками.

## Что сделать

Реализуй `useInterval` так, чтобы:
- каждые `delay` мс вызывался `callback`;
- `delay === null` останавливал интервал;
- при смене `delay` интервал пересоздавался;
- при смене `callback` интервал не сбрасывался (иначе тик сбивается на каждом рендере);
- подписка снималась при unmount.

Демо менять не нужно: оно специально читает `count` и `step` из замыкания, чтобы был виден stale closure.

Чтобы открыть в StackBlitz, создай проект Vite React TypeScript и замени `src/App.tsx` этим файлом.

## Как проверить

- Счётчик растёт каждую секунду: 1, 2, 3, а не застревает на 1.
- Пауза останавливает таймер, "Продолжить" идёт дальше с того же числа.
- Переключение шага на 10: следующий тик прибавляет 10, секундный ритм не перезапускается с нуля.
- В консоли каждое `tick` совпадает с числом на экране.
