# Оптимистичное обновление с откатом

Время: 30-40 минут (около 15 на код, остальное на обсуждение).

Кнопка лайка. По клику счётчик должен сразу вырасти, не дожидаясь сервера. Если запрос упал, значение возвращается как было.

## Что сделать

Напиши хук `useOptimisticState(initial)`:
- возвращает `[value, pending, run]`;
- `run(next, request)` сразу показывает `next` и ставит `pending` в `true`;
- если `request()` успешно, оставляем `next` и снимаем `pending`;
- если `request()` упал, откатываем `value` к тому, что было до клика, и снимаем `pending`.

Код пиши в `src/useOptimisticState.tsx`. `saveLike` уже есть в `src/api.tsx`. Компонент в `src/App.tsx` готовый, его менять не нужно.

## Как проверить

- Клик сразу меняет 0 на 1, кнопка в этот момент неактивна.
- Если "Сервер отвечает ошибкой" включён, через секунду снова 0 и кнопка активна.
- Если выключен, единица остаётся.
