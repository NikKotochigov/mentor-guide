# React: задачи Middle+ / Senior

Пять задач на проектирование хука или небольшого API, либо на исправление бага в модели React. Время каждой: 30-40 минут.

В каждой папке:
- `README.md` - условие для кандидата
- `SOLUTION.md` - решение и вопросы для обсуждения, только для интервьюера
- `starter/` - заготовка для StackBlitz (Vite + React + TypeScript)

Как открыть задачу в StackBlitz:
1. Зайти на [stackblitz.com](https://stackblitz.com), выбрать Open or create, затем Upload и перетащить папку `starter`.
2. Либо создать проект Vite / React / TypeScript и скопировать туда содержимое `starter`.

Задачи:
1. [Мини-стор](./01-mini-store/) - глобальный стор на `useSyncExternalStore`, компонент подписан только на свой кусок state.
2. [Данные через Suspense](./02-suspense-cache/) - кэш промисов на уровне модуля, компонент приостанавливается, пока данных нет.
3. [Оптимистичное обновление](./03-optimistic-update/) - хук, который сразу меняет UI и откатывает значение, если запрос упал.
4. [Поиск с гонкой запросов](./04-search-race/) - дебаунс, отмена устаревшего fetch и актуальные результаты в списке.
5. [Сброс state через key](./05-reset-state-key/) - при смене контакта черновик должен сбрасываться, вложенный компонент не должен забирать фокус.
