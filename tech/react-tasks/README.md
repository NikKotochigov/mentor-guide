# React: задачи для мок-собеса

Задача целиком лежит в одном файле `App.tsx`, условие написано комментарием в начале файла.

Как открыть в StackBlitz:
1. Создать проект [Vite React TypeScript](https://stackblitz.com/fork/github/vitejs/vite/tree/main/packages/create-vite/template-react-ts).
2. Открыть `src/App.tsx` и заменить его содержимое кодом из `App.tsx` задачи.

В папке задачи:
- `App.tsx` - условие и стартовый код для кандидата
- `README.md` - то же условие отдельным файлом
- `SOLUTION.md` - решение и вопросы для обсуждения, только для интервьюера

Задачи:
1. [Поиск с гонкой запросов](./04-search-race/) - дебаунс, отмена устаревшего fetch и актуальные результаты в списке.
2. [Сброс state через key](./05-reset-state-key/) - при смене контакта черновик должен сбрасываться, вложенный компонент не должен забирать фокус.
