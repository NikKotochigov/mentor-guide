# Сброс state через key

Время: 30-40 минут (около 15 на код, остальное на обсуждение).

Чат с несколькими контактами. В коде уже есть список и поле черновика, но в нём два бага.

## Что сделать

1. Поле теряет фокус после каждого введённого символа. Найди причину и исправь. Код поля - в `src/Chat.tsx`.
2. При переключении контакта в поле остаётся черновик прошлого собеседника. Коллега предлагает `useEffect`, который сбрасывает `draft` при смене `contact.id`. Сделай проще и без лишнего рендера. Список контактов - в `src/App.tsx`.

API чата и данные менять не нужно.

## Как проверить

- Можно набрать несколько символов подряд: курсор остаётся в поле, текст не сбрасывается.
- Переключение на другого контакта показывает пустое поле и новое имя в подписи.
- Возврат к предыдущему контакту тоже показывает пустое поле, а не старый черновик.
